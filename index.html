Clean setup

1

Import Proton

GameNative → Settings → Wine/Proton Manager → Import WCP Package.

proton-11.0-90624-arm64ec.wcp
2

Import DXVK

Settings → Contents Manager → Import WCP Package.

dxvk-2.4.1-wow-aarch64-test.wcp
3

Import Turnip

Settings → Driver Manager → Import ZIP from device. Do not unpack it.

A830/A840: Turnip-V32-RP6sched-A8xx.zip
A740/RP6: turnip-wow-scheduler-test.zip
4

Create one card

Add Battle.net-Setup.exe as the custom game. This card/container will later run both Battle.net and WoW.

Install Battle.net

Install Battle.net to its normal C: location. Do not install Battle.net to D: or G:.

C:\Program Files (x86)\Battle.net

Install Forever

Open Battle.net in the same container, then install WoW Forever to:

C:\Program Files (x86)\World of Warcraft

Wait for the download to finish and confirm:

C:\Program Files (x86)\World of Warcraft\_classic_beta_\WowB-ARM64.exe

Direct launch

Use scripts/Launch-WoW-Direct.bat. It starts the ARM64 client with -d3d11.

Updating later

No second copy is required.

  1. Launch Battle.net inside the same GameNative card/container using Launch-BattleNet.bat.
  2. Let it patch C:\Program Files (x86)\World of Warcraft.
  3. Close Battle.net.
  4. Launch WoW again with Launch-WoW-Direct.bat.

Troubleshooting

Battle.net is black or blank

Try the scripts in this order: Launch-BattleNet.bat, Launch-BattleNet-disable-gpu.bat, then Launch-BattleNet-in-process-gpu.bat. Battle.net's Chromium UI can be temperamental under Wine.

Pipeline assert / game silently exits

Confirm the patched Turnip driver is selected. Stock V32 can render cleanly at first but hit the WoW pipeline issue later.

Corrupted stripes

That usually means the Turnip base is wrong for the GPU family. The old A740-oriented RP6 driver is not the correct choice for A830/A840.

A830

Keep TU_DEBUG=noconform,sysmem.

1080p fails

Return to 1280×720 while testing. The A840 test found 1080p could trigger a different shader path and reproduce the pipeline failure.
